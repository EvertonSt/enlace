1. OVERVIEW
================================================================================

Enlace is a full-stack ISP (Internet Service Provider) management platform
built for a fictional fiber optic company in Paripiranga, Bahia, Brazil.
It provides customer self-service, NOC (Network Operations Center) staff tools,
and a mobile app — all backed by a shared API server.

The platform manages:
  - Fiber optic internet plans (5 tiers, R$59.90 - R$399.90/month)
  - Customer accounts (12 customers seeded)
  - Support tickets with AI-powered triage (25 tickets seeded)
  - Real-time outage tracking with maps (6 outages seeded)
  - Billing and invoices (24 invoices seeded)
  - Field technician dispatch (4 technicians seeded)

3. SERVER (API)
================================================================================

Location: apps/server/
URL (Production): https://server-production-5ffa.up.railway.app
Framework: Fastify 5

API Endpoints:
  POST   /api/auth/register       - Customer registration
  POST   /api/auth/login          - JWT login (returns token)
  GET    /api/auth/me             - Current user info
  GET    /api/plans               - List ISP plans
  GET    /api/tickets             - List tickets (customer's own)
  POST   /api/tickets             - Create support ticket
  PATCH  /api/tickets/:id         - Update ticket status
  GET    /api/tickets/:id/triage  - AI triage details
  GET    /api/outages             - List outage events
  POST   /api/outages             - Create outage (staff)
  PATCH  /api/outages/:id         - Update outage status
  GET    /api/customers           - Customer lookup (staff)
  GET    /api/invoices            - List invoices
  POST   /api/invoices            - Create invoice (staff)
  GET    /api/technicians         - List technicians
  POST   /api/technicians         - Create technician (staff)
  PATCH  /api/technicians/:id     - Update technician
  POST   /api/technicians/:id/assign - Assign ticket to tech
  PATCH  /api/technicians/jobs/:id/complete - Complete a job
  GET    /api/analytics/overview  - Dashboard KPIs
  GET    /api/analytics/tickets/* - Ticket analytics
  GET    /api/analytics/outages/* - Outage analytics
  GET    /api/analytics/customers/* - Customer analytics
  GET    /api/analytics/revenue/* - Revenue analytics
  GET    /api/analytics/technicians/* - Tech performance
  GET    /ws/outages              - WebSocket: real-time outages
  GET    /ws/tickets              - WebSocket: real-time tickets
  GET    /api/health              - Health check

Key Features:
  - Rate limiting: 100 req/min global, 10/min login, 5/min register
  - WebSocket real-time broadcasts for outages and tickets
  - AI triage (rule-based or Claude/OpenAI)
  - Daily reset scheduler for technician completedToday counter
  - JWT authentication with role-based access (customer/staff)
  - Transaction-safe technician assignment

Environment Variables:
  DATABASE_URL     - PostgreSQL connection string (Railway auto-injects)
  JWT_SECRET       - Secret key for JWT signing
  TRIAGE_PROVIDER  - "rule-based", "claude", or "openai"
  PORT             - Server port (default: 3001)
  HOST             - Bind address (default: 0.0.0.0)

9. REAL-TIME FEATURES
================================================================================

WebSocket Routes:
  ws://host:3001/ws/outages  - Broadcasts outage created/updated events
  ws://host:3001/ws/tickets  - Broadcasts ticket created/updated events

Message Protocol:
  { type: "outage:created", outage: { ... } }
  { type: "outage:updated", outage: { ... } }
  { type: "ticket:created", ticket: { ... } }
  { type: "ticket:updated", ticket: { ... } }

Clients:
  - Desktop NOC Dashboard: useOutageWs hook (auto-reconnect 3s)
  - Desktop Support Queue: useTicketWs hook (auto-reconnect 3s)
  - Web OutagesPage: useOutages hook (connects to ws://.../ws/outages)
